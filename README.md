# بيتي 360°

جولة 360 واقعية ببيت انرسم مخططه على ورقة: 5 غرف و3 ستايلات (عصري دافي، كلاسيكي، صناعي).
الرندر بـ Blender (Cycles) بخامات وأثاث مجانية (CC0) من Poly Haven، والعارض Pannellum.

**افتح الجولة:** https://hanna-alfarah.github.io/house360/
